# v2026.11.17 更新日志

- **夜间主题**：新增深色界面，日历、设置页、日期编辑及更新弹窗配套适配；主题选择立即生效，下次启动继续使用。
- **标题栏一键切换**：右上角新增月亮／太阳按钮，与设置页的夜间主题开关同步；太阳图标采用圆形中心和独立光芒，便于辨认。
- **夜间日历更清晰**：计入工作日统计的记录使用深绿色，不计入的记录使用蓝色，便于区分两类记录，保留选中边框、备注及餐补标记。

本次发布使用 Windows x64 Release，客户端与安装程序版本为 `v2026.11.17`，
源码发布分支为 `main`，注释标签为 `v2026.11.17`。
已安装较早版本的客户端可检查更新，也可以重新下载安装程序。
