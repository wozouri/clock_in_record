# v2026.11.04 更新日志

## r2 修订

- **更新日志更易阅读**：修复长日志被裁切的问题，采用无边框阅读排版，突出段落标题；短日志按内容收起留白，长日志可滚动查看，底部操作按钮保持可见。
- **启动新版提示**：启动后自动检查一次更新，发现新版时显示提示并点亮下载图标；已是最新版或服务暂不可用时保持静默。

客户端和安装程序仍使用 v2026.11.04，修订版源码标签为 `v2026.11.04-r2`，发布文件名附带新的源码提交号。已安装 v2026.11.04 的客户端需重新下载安装程序；较旧版本可自动更新。保留原版文件及切换前的清单，以便回退。

发布回归将启动检测放在独立进程运行，避免额外主窗口的生命周期影响后续界面用例；更新日志、启动新版提示、无更新及服务失败静默行为均在发布前检查。

## 原有更新

- **空白日期也能记备注**：在日期编辑中关闭“记录上下班时间”，即可只保存备注。日历保留备注提示，支持复制、导入导出及撤销，不计入工作天数、工时和餐补统计。
- **时间调整支持循环**：选中小时或分钟后，可用键盘上下键或鼠标滚轮循环调整。分钟支持 `00 ↔ 59`，小时支持 `00 ↔ 23`；调整分钟时小时保持不变。
- **全选后可直接输入完整时间**：支持输入或 Ctrl+V 粘贴 `08:59`、`8:59`、`0859`，自动规范显示为 `08:59`。`859`、`8:5` 等简写可按回车或离开输入框确认；焦点在时间框内时，回车只确认时间，不触发弹窗保存或关闭。非法输入不会覆盖原时间，按 Esc 可取消尚未确认的输入。
